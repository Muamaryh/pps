# LSM Paguyuban Pizza Sandy Shores (PPS)

Official Web Portal untuk **Lembaga Swadaya Masyarakat (LSM) Paguyuban Pizza Sandy Shores**.

---

## 🍕 Tentang Organisasi

LSM Paguyuban Pizza Sandy Shores adalah wadah persatuan, pemberdayaan, dan advokasi sosial bagi masyarakat di kawasan Sandy Shores dan sekitarnya. Bergerak dengan prinsip gotong royong, kemandirian UMKM, serta kemitraan konstruktif bersama otoritas kota.

### 🌟 Fitur Utama Website:
- **Liquid Glass Neo-Brutalism Design**: Estetika modern berani dengan palet khas Kuning Pizza (`#FACC15`) & Merah (`#DC2626`).
- **Dark & Light Mode Taktil**: Dilengkapi skema warna anti-glare untuk kenyamanan mata pada mode gelap.
- **3-Line Sequential Typewriter**: Animasi ketik dinamis di Hero Section.
- **Struktur Pengurus Interaktif**: Filter kategori kepengurusan & live search.
- **Galeri Dokumentasi Lapangan**: Terintegrasi arsip kegiatan lengkap dengan tanggal & lokasi (logo kalender & waypoint).
- **Custom Brutalist Date Picker**: Pemilih tanggal berbahasa Indonesia (*Kamis, 15 Oktober 2026*).
- **Panel Administrator (`/admin`)**: Manajemen konten dinamis (brand, profil, pengurus, foto galeri) dengan kompresi gambar otomatis.
- **Cloud Database Synchronization**: Terhubung secara realtime dengan Firebase Firestore & local storage fallback.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Database**: [Firebase Firestore](https://firebase.google.com/)
- **Fonts**: Outfit, Plus Jakarta Sans, JetBrains Mono

## 🚀 Menjalankan Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/Muamaryh/pps.git
   cd pps
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. **Build untuk produksi:**
   ```bash
   npm run build
   ```

---

## 🔐 Akses Panel Administrator

Kunjungi endpoint `/admin` atau klik ikon gembok di bagian footer untuk mengakses dashboard pengelola portal.
